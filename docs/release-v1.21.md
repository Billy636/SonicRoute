# SonicRoute v1.21 正式版

2026-10-09 · [GitHub Release](https://github.com/kunkunkunQoQ/SonicRoute/releases/tag/v1.21)

本版更新完整界面与自动化编辑体验，改进关闭窗口后的资源清理，采用事件通知跟随前台应用和麦克风静音，并更换透明耳机图标。

## 下载与升级

| --- | --- | --- |
| Lite x64 | [单 EXE](https://github.com/kunkunkunQoQ/SonicRoute/releases/download/v1.21/SonicRoute-v1.21-Lite-x64.exe) | x64 .NET 8 Desktop Runtime |
| Lite ARM64（实验） | [单 EXE](https://github.com/kunkunkunQoQ/SonicRoute/releases/download/v1.21/SonicRoute-v1.21-Lite-arm64.exe) | ARM64 .NET 8 Desktop Runtime；当时未完成真机完整验证 |

支持 Windows 10 2004+ / Windows 11。升级前正常退出旧实例，再运行新版；设置与规则沿用原数据目录。也可通过 [Microsoft Store](https://apps.microsoft.com/detail/9NQZGRTPM1NT) 安装和更新。

## 主要变化

- **界面与设置**：统一导航、卡片、开关和文本输入样式；改进深浅主题、Hex/RGB/HSL 颜色编辑与选色，设备名称可编辑、清空后恢复原名称。
- **自动化编辑**：规则卡片显示真实名称、操作和触发摘要；保留搜索/筛选与滚动位置；支持展示顺序拖动。名称留空时自动选择可用的规则编号。
- **常用操作与规则执行**：复制规则执行命令、托盘常用规则、音量滑块右键档位；新增执行另一条规则及每步可选失败后停止。
- **关闭资源与后台状态**：窗口关闭时解绑资源并取消未提交的界面更新；以前台和设备事件更新状态，并在发现可见故障时临时检查恢复。
- **图标**：采用透明耳机图案，托盘轮廓随任务栏主题变化。

## 验证与适用边界

以下数字属于 v1.21 发布时的历史验证。Lite、Legacy 各完成 144 项功能检查及 34 项实际主面板目标检查；真实双前台目标普通切换 12/12 正确，密集切换后最终目标正确。两版及 ARM64 构建无错误；ARM64 仅编译和包结构检查，未完成真机运行验证。

当时隔离发布构建关闭窗口后，总工作集为 11.24–16.61 MiB，私有提交均值约 114.91 MiB。这些是特定本机测试结果，不能推导当前版本的内存表现，也不支持“私有内存低于 30 MB”的结论。工作集整理不等于释放私有提交。周期状态查询停止已验证，整体 CPU 降低没有实测支持。

正常事件监听不能保证每款驱动都不丢通知；静默丢失未必能自动发现，遇到兼容性问题可开启实验兜底。音频会话超过短期重试窗口才出现时，需要下一次前台、手动或设置刷新触发。自动化、电平与规则目录恢复仍保留各自必要的定时任务。

当前使用方法见 [Wiki：使用指南](https://github.com/kunkunkunQoQ/SonicRoute/wiki/01-%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97)与[自动化规则](https://github.com/kunkunkunQoQ/SonicRoute/wiki/04-%E8%87%AA%E5%8A%A8%E5%8C%96%E8%A7%84%E5%88%99)。

## v1.21 历史附录

本附录保留 v1.21 阶段记录中具有历史价值的操作细节、检查范围与边界。测量数字及通过项只对应所述阶段、构建和测试环境，不构成 v1.22 或当前版本的性能/兼容性承诺。

### 自动化与音量改进记录

v1.21 阶段记录了自动化列表卡片、规则名称/摘要/触发信息展示、搜索和筛选、拖动排序，以及编辑区状态恢复。拖动规则的展示顺序按 ID 保存；排序不改变自动触发顺序或规则步骤顺序。卡片图标、启用状态颜色、禁用规则手动运行、步骤失败处理均按当时实现检查。

该阶段还记录了复制执行命令、托盘常用规则、音量右键 25%、50%、75%、100%档位，以及逐步骤失败后停止和“执行另一条规则”。规则执行器检查了目标停用时仍可直接调用、调用失败传递、循环及深度限制等行为。PowerShell/程序动作以是否成功启动判断，不等待外部执行结束或检查脚本退出码。

Lite 与 Legacy 各通过 34 项编辑器隔离检查；其中应用候选数据共享检查记录为 20 个下拉共用 100 个数据对象。阶段记录明确未测本次改动的实际进程内存或 CPU 降幅。ARM64 只做编译，没有真机运行测试。

### 主题与设置阶段记录

阶段 45 记录 Lite x64、Legacy x64 开发构建及 ARM64 编译；Lite 和 Legacy 各通过 40 项隔离检查，覆盖设备名称保存/清空恢复、首次设置行为、Hex/RGB/HSL 校验、色谱选色、输入框编辑与深浅模式截图等。该阶段没有模拟输入法组合输入，也没有重跑资源采样。

阶段 46 为延迟创建设备行、编辑器引用释放、下拉数据共享和默认规则名称补充检查：Lite 与 Legacy 各通过 34 项。该阶段没有重新采样实际进程内存或 CPU。

阶段 47 检查关闭资源清理，并进行独立隔离内存测量。窗口关闭时释放事件、计时器、动画及界面引用，取消旧窗口尚未开始的读取/排队更新，已提交操作继续完成；快速面板待提交音量快照会写完。程序不主动强制 GC；关闭后延迟 1.5 秒整理空闲工作集，重开时取消整理。整理不等于释放私有提交，重新打开时系统可能读回页面。本机隔离发布版稳定后台私有工作集为 4.52–5.80 MiB，私有提交约 119 MiB；结果仅属于本机该次测量。Lite 与 Legacy 各通过 30 项关闭检查、34 项回归检查及 1 项汇总；Lite x64 发布、Legacy x64 Release 与 Lite ARM64 编译为 0 错误。ARM64 仅编译，未做真机运行。

阶段 47 的测量范围与限制不等于对阶段 43 完整性能报告的重新测量。以上各阶段数据不得转述为当前版本测值，也没有证据宣称母语支持、ARM64 真机验证或私有内存低于 30 MB。

### 后台检查兜底与名称（阶段 49）

实验设置新增“后台定时检查兜底”，默认关闭。关闭时正常状态依靠前台应用和麦克风状态通知；没有匹配到音频时短暂重试，发现监听故障时临时检查并恢复。打开后持续保留前台约 1.5 秒及麦克风约 2 秒检查；自动化规则等其他定时任务仍按原策略运行。

主界面与两种快速面板顶部统一显示 `SonicRoute` 并保留版本号；应用图标使用透明耳机图案，托盘轮廓随任务栏主题变化。商店包补齐无底板图标资源与索引。此处为 v1.21 历史记录。
